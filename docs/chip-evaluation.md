# 一期质量与成本评测

## 实际证据与验收结论

当前是可构建的行业定制代码，**尚未达到持续内部试运营验收**。主要欠缺Docker/PostgreSQL、模型配置与人工标注校准、实际后台预览和多轮自动任务。

- 36个候选（任务书28个+8个补充原始工具链/新闻入口）均已实际试抓；9个种子源取得近期条目和至少一篇可读正文。10个源取得近期可核日期条目，其中一个正文不可提取。不是15个稳定自动源，缺口如实保留。
- 采集脚本直接使用上游原生RSS/JSON/web_list、过滤和正文提取，无付费渲染，不绕过访问限制。网页列表最初选择器无匹配，按实际DOM修正地平线/爱芯等；仍无日期则禁用。爱芯补卡片日期正则后复验通过。source-probes.json记录最终状态，候选不等成功，种子启用不等DB已启用。
- 已运行类型检查、前端构建、274项无需数据库的原生测试，均通过；15项网页HTTP/缓存/边界测试通过。首轮沙箱端口EPERM后获本地监听执行权限重跑；提示词动态占位符不被understand调用方支持的问题改为静态白名单，未绕过模板校验。
- npm test在测试库连接阶段因本地环境/沙箱拒绝连接失败；未执行任何迁移，数据库测试未通过。Docker命令不存在。完整test:web因缺Playwright浏览器失败并停止；另用系统Chrome检查18个桌面/手机路由响应，均200且无横向溢出，明确使用测试API。
- 首页/全部/热点/主题/关于/条款/隐私/Agent及搜索入口已检查。日报周报月报生成、真实事件归组、主题实际内容和管理员真实会话未端到端验收。上游引擎及鉴权未改写。

## 标注与模型评测

真实采集元数据队列：industry/review-queue.jsonl，共20条，仅标题/URL/发布时间，不存全文。所有业务标注尚为空；不是100–200条人工金标，不能计算精确率或召回率。公开网页可访问不代表摘要事实已核验。

操作：业务人员逐条读原文，标是否相关、是否值得精选、主分类、主体及理由；补足有权处理的正文，按上游docs/selection.md转成金标JSONL（保存在.data，不进Git）。分开发/留出集，纳入营销、普通应用、重复稿及新厂商难例；至少100条后用 `node --env-file=.env scripts/eval-selection.ts --gold .data/chip-gold.jsonl --no-import`。评测需要模型key，当前未运行。评分阈值与双评分结构保留，未假称85%精确率/80%召回率。

去重利用原生URL/内容身份与事件归组；未调用真实归组模型，当前没有真实事件聚合准确率。下一轮构造同事件多源/后续量产/不同型号对照并按docs/grouping.md评测。

重点查发布与定点/SOP/交付、同比期间与累计、精度/稀疏/功耗范围、型号排歧、原文URL/日期、影响推断分离。Thor电影/X7车型属于负例；未知新厂商保留UNKNOWN。只把提示词规则写入不等模型已经遵循，需实测。

## 成本

真实模型调用0次、付费抓取0次；本项目未提供模型key，成本指标不宣称已测。公开HTTP试抓不调用LLM。原生后台有调用回执、token和每分钟/小时/天预算熔断，预算是调用数量，不等人民币消费上限。

成本=输入token/1e6×输入单价+输出token/1e6×输出单价+各付费抓取次数×单价；实际服务商价格、缓存与税费由启用者核实。先设预算再打开开关；首次回填每源最多4条、日期起点2026-11-01，36候选只有9个种子开关为true。阶段成本先跑20条真实样本再外推，不用上游演示成本作本站实测。
